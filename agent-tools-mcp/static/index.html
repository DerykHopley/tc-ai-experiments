How this maps to LangChain

create_agent() builds a LangGraph state graph with two nodes. The model node calls Claude with the conversation so far and the tool schemas. If Claude replies with tool calls, the graph routes to the tools node, which runs them and appends the results as ToolMessages, then loops back to the model. When Claude replies without tool calls, the graph ends.

MCP tools come from MultiServerMCPClient.get_tools(), which asks each MCP server for its tool list and wraps each one as a normal LangChain tool. To the model they look identical to local tools; the difference is that calling one sends a JSON-RPC request to another process.
